# 立面モード（外壁立面）の設計意図

立面モード（appMode `'facade'`。ModeBar の「立面」）。建物の外壁立面4面を1枚の縦スクロール図に描く表示専用のモード。用語は `glossary.md`「立面モード」。純モジュールは `facade/`、状態は `modes/FacadeModeState.js`。

## 仕様（問題.md 原文の要旨）
- 外壁立面4面。方位指定があれば東南西北の順、無ければ 3時=東・6時=南・9時=西・12時=北。
- 各面は見切れない**統一倍率**で縦に並べる。GL から上を描き、▽GL を付ける。
- 展開描画で使えるものは兼用する。合理性と即応性を優先する。

## 展開モードとの関係（再利用の範囲）
- `facade/` が引いてよい `elevation/` は **elevationPrimitives・elevationLayout・elevationStyle の3本だけ**（線プリミティブ語彙・縦積みとスクロール・線種定数）。逆向き（`elevation/` が `facade/` を引く）も禁止。`facade/importGraph.test.js` が固定する。
- 断面エンジン（`section/`・`space/`）や平面の解決器（`planSolids`）は使わない。理由: 立面は「各階の外壁を全高で占める箱の下側包絡」で足り、室内の空気セル・層スタックが要らない。重い解決器を通すと即応性を損ない、室内向けの規則（断面の中は描かない等）を外面へ持ち込むことになる。
- `facade/` は store.js・snap.js・appViewport.js・storage/・.jsx・konva を静的に引かない（node:test から単体 import できる純モジュール。同テストで固定）。

## 向きと左右
- 平面は y 下向き正。面の法線 n は建物から見る人へ向く。投影は `u = ny·x − nx·y`（図の右が正）、`depth = −(nx·x+ny·y)`（小さいほど手前）。図の Y は `glZ − z`（GL が Y=0、上が負）。
- **東立面＝左が南・右が北**（東から西を見ると右手が北。リード裁定）。
- 方位は `northAngleDeg` の受け口だけを持つ（90°単位に丸めて割当てをずらす）。保存データに方位項目は無いので App は null を渡す。

## 外壁線と階ごとの奥行き
- 外壁線の供給源は `finish/finishGuideGeometry.js exteriorGuideSegments`（**外面**。`outwardSign`・`axisCLId` を立面のため追加）。outer と courtyard の両方を扱うが、中庭は包絡に負けて描かれない。
- 階ごとに「手前向き線分の深さの下側包絡」を作り、縦線は包絡の端と深さの変わり目、横線は各階の上端・下端。**隠れ判定**は自階を含む各階の包絡がより手前なら隠れる（同じ階の手前の袖壁にも隠れる）（100mm 標本＋0.5mm 二分探索で見え方の変わり目を詰める）。
- 面一の階境の線は描かない（GL に乗る下端は▽GLの線が兼ねる）。FL 線は描かない。
- 描かないもの: GL 以下・地階・検討案・屋根専用平面・基礎。最下の地上階の zLo は GL、各階の zHi は次の階の FL、最上階は `eaveTopZMm`。

## 倍率と配置
- 倍率＝どの1面も縦横とも収まる最大の `NICE_SCALE`（`chooseScale` 流用）。注記（GL の延長・見出し）の実画面 mm を差し引いた枠で決め、倍率確定後にモデル mm へ換算する。
- 4面は縦に積み縦スクロール（`layoutBands` 流用）。「4面を1画面に」へ切り替えるなら、枠の高さを4面合計にするだけでよい。
- ▽GL は polyline 3点＋text、見出し「東立面図」は text。**新プリミティブ型は作らない**。

## モード境界と State
- 突入で**全採用階**の壁鮮度を判定する（`wallRefresh.js refreshWallsForFacadeEntry`。`planeIds` null。離れた階の古い外壁が図に出るのを防ぐ）。表示専用なので exit・undo は無い。立面中の undo/redo には追従せず、突入時のスナップショットを描く（展開と同じ割り切り）。
- State は init で全階 peek→inputs→extents→scale→注記換算→model を作る。init は reject しない。読めない階・外壁や建具の取得で例外の階（`skipped` の ERROR）があっても残りの階で描き、`materialError` のトースト（`FACADE_INIT_ERROR_MESSAGE`）で知らせる。外壁が1本も無ければ `FACADE_EMPTY_MESSAGE`。倍率は viewSize で変わるので reaction で model を作り直す（computed にしない理由は State 冒頭コメント）。

## 屋根（S2）
- region の出どころ: 下屋＝各採用階の `leanToPlanRegions`（軒高＝その階の FL）、主屋根・屋根区画＝最上階の `topRoofPlanRegions`（軒高＝`eaveTopZMm`）。陸屋根は region なし＝描かない。region の解決は **State 側**（`roofFramingRegions.js` が storage を推移的に引くため `facade/` から引けない。帯ビルダーの流儀で inputs に渡す）。
- 屋根面の高さ `z = eaveZ + k·T(q) − k·max(dx,dy) + k·max(ux,uy)`（k＝勾配/10、T＝`drainArrivalTime`、q＝最近傍の屋根範囲内の点、dx/dy＝水下の辺を越えた分で下げる、ux/uy＝片流れの水上の辺を越えた分で上げる、けらばは水平）。平面の `roofZAtOf`（軒の出＝FL と割り切る見下げ用）とは**別の式**で、相互参照コメントを付けてある。valid でない・勾配 0・outlineOnly は軒高の水平線だけ（skipped に `ROOF_FLAT_FALLBACK`）。
- 線種: 軒先・けらば・棟＝SILHOUETTE、隅木・谷木＝DETAIL。隅木が外形線に重なる部分は外形線に譲る。屋根線は `kind:'roof'`。
- 屋根による隠れ: 手前の屋根部分の z 範囲 [min − 100, max − ε] を隠す（100＝垂木＋野地の目安）。屋根の輪郭上の点は u±SAMPLE_OFFSET の**2本の視線で両方隠れたときだけ**隠す（水上側のけらばが自分の屋根で消えない）。
- 頭打ち: 屋根が載る階の壁上端は屋根面の高さ（妻側は屋根面まで立ち上がる。その階の上端の横線は描かない）。下屋が付く階の壁下端は壁面での屋根面高さ（取り合い線）。面一の角の縦線は屋根面より下を描かない（`continuedFace`）。軒の出の帯に立つ上階の角の縦線は屋根面まで下ろす（`wallBottomAt`）。

## 建具（S3）
- 対象＝外向きの外壁線分に乗る建具（軸 CL と向きが線分と同じ・`wallSide` が線分の `outwardSign` と同じ・中心が線分の範囲内）。`wallSide` で選べるのは、`generateExteriorWalls` が外壁を常に室外側に作るため。中庭の建具も対象に入り、外周の包絡に隠れて出ない（屋外部屋が外周に面していれば見える）。
- 左右: **姿図は壁座標の昇順で描かれる**（`hingeSide<0` の吊元が coord1 側）。面の u が壁座標と逆向き（du/dc<0。既定の向きでは東・北）の面だけ `mirrorPrimitiveX` する。展開図の dirSign<0 と同じ規則で、「室内から見た向きを裏返す」のではない（見る側に依らない世界の向きから写す）。
- 隠れ: 中心と四隅の 5 点のうち 1 点でも見えれば丸ごと描く（線ごとの切り欠きはしない）。中心だけだと取り合いをまたぐ窓が消える。
- 三方枠は枠の三方の線だけ（展開図のアキのバツ・「ア キ」は描かない。外からは素通しの開口）。カタログに無い種別は飛ばして数える（`noEntry`）。
- 見付の 1px 保証（`minFaceMm`）は展開図と同じ式を State が倍率から求めて渡す（倍率が変わると作り直す）。
- 建具の読み取りで例外の階は `skipped`（ERROR）に載せ、その階の壁は描く。

## 既知の限界
- S1: 外面は壁が無い区間で通り芯へ落ちる／地階が GL より上へ出る部分は描かない／stories>1 の最上階は `eaveTopZMm`／最下の地上階に graph が無いと次の階が FL から浮く。
- S2: 屋根どうしの谷・棟違い・区画の取り合いは交線を作らない／最近傍 q は L 字の入隅の外側で近似／L 字の片流れの水上側は水平のまま／けらば出幅 57.5 未満は妻壁を頭打ちしない／軒の出の帯の隠れは厚み 100 の近似。
- S3: 屋根や壁に一部隠れる建具も丸ごと描く／内外の線種（外開き実線・内開き破線は室内側の規約）は入れ替えない／部分指定の FL 段差は無視して階の FL に置く（展開図の floorDyAt に当たる処理が無い）／境目に乗る建具は最初の線分に割り当てる。
