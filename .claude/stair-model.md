# 階段モデルの設計意図

## 実段数 = 踏面数 + 1（不変条件）
n段の区間（直進部・アーム）は踏面（区割り線で分割される領域）をn-1枚生成する。区間長・踏面境界・段数字位置はすべて「n-1等分」を基準に計算する。過去の実装でnのまま等分する誤りが複数のタイプ別関数に混入したため、この換算は`stairGeometry.js`内の共通ヘルパーへ一本化し、各タイプの生成関数側では実装しない。

## 「階段」＝直進部＋踊場・周回部の組み合わせ
7タイプ（STRAIGHT/STRAIGHT_LANDING/SWITCHBACK/WINDING/L_TURN/FLARED/OPEN_WELL）は、直進部（実段差>1の走行区間）と踊場・周回部（実段差1以上で他区間とI/L/U字接続する平場）の並びとして表現する。タイプの違いは「どちらをいくつ・どう並べるか」の宣言に還元する。

## タイプ依存が許されるのは「描画・生成手順」のみ
実段数から区間長・踏面境界・段数字番号・接続続き番号を求める処理は、必ず「階段」側の共通ヘルパーを経由し、タイプ別に再実装しない。タイプごとに異なってよいのは、区間を実座標へ写像する幾何（矩形/扇形/C字frame等）だけ。
- WINDING/FLAREDの回り段：実段差ぶんの踏面をpivotから扇形に放射配置（`perim`系）
- OPEN_WELL：3直進部+2踊場をC字にたどる独自frame写像（`makeFrame`を使わない）

これらは形状描画の個別実装として残してよいが、内部で扱う「区間長」「踏面境界の位置」自体は共通ヘルパーが返した値をそのまま使う（タイプ側でn/n-1換算を再計算しない）。

## 接続点のルール
- 区間初段の段数字は、前接続区間の文字位置の続き番号を振る
- U字・L字接続時、段数字は外寄りに配置する
- 階段設置階上階に接続する最後の区間のみ、最後の踏面線と段数字をパーツ外に描く
- 段数字は詳細モードのみ描画する（上位層で判定していることを描画側で前提にしてよい）

## 移行用の変数命名（このリファクタ期間限定）
実段数由来の値を新ロジックで再計算する箇所は、旧値と並置して目視比較できるよう `_new` サフィックスを付ける（移行完了・旧実装削除後は通常名へ統合してサフィックスを剥がす）。ユーザー入力の踏面数指定に由来し、以降の処理過程で島状の不整合（区割りが連続せず飛び地になる等）が混入していないか追跡が必要な派生変数には `_checked` サフィックスを付ける。
