# 天伏モード（見上げの天井伏図）

天井伏図モード（appMode `'ceiling'`。ModeBar の「天伏」）。見上げ図の描画と、天井欄の指定を行うための専用モード。用語は `glossary.md`「天伏」。

## 構造（S1a'）
- **仕上げモードとは独立**: 専用の State（`modes/CeilingModeState.js`）・専用パネル（`ceiling/CeilingPanel.jsx`。内部／階段タブ。当面は読むだけ）を持つ。仕上げ表との兼用案は捨てた（ユーザー裁定 2026-10-10）。共有するのは**データ（Room の天井欄）と純モジュール**（部屋の述語 `finish/interiorTabRooms.js`・階段タイプ表記）だけ。UI の部品や State を借りない。
- 境界処理（モード切替時の他階反映など）は持たない。パンのみのポインタ分岐、CL 種別ポリシーの ceiling 行は登録済み。

## 見上げ（S1b）
- 描画は平面の断面解決を**向きだけ反転**して流用する（鏡像ラッパー）。切断高は平面と同じ階の値（専用の属性は作らない。ユーザー裁定待ち）。方式・窓規則を使わない理由・天井の立体・自階で描く種別・鍵は `.claude/plan-section.md`「見上げ（天伏。S1b）」。
- 天井の面は `ceiling/ceilingSurfaces.js` が唯一の算出（部屋ごとのセル矩形と天井高）。天井の実体（材料・区画・天井芯）が入ったとき、天井立体の中身はこの関数の差し替えで済ませる。

## 今後（裁定待ち）
- 区画（天井の分割）・天井材欄・天井芯は未実装。データモデルをどう持つかは裁定してから。
- 同じ高さで隣り合う部屋の天井の境目の線は現状消えない（立体が部屋ごとのため）。区画を持つときに「同じ高さ・同じ材は1面」へ寄せるのが筋。
- 天井面の高さは部屋の床段差を含む（裁定）が、壁の上端（`planSolids.js wallCeilZ`）は床段差を含めない。両者がずれる部屋（段差のある部屋）では天井と壁の高さが揃わない。
